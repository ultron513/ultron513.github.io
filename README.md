# Ashish Patra — Portfolio

Personal portfolio website for Ashish Kumar Patra.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- GSAP
- Lenis
- React Three Fiber
- Zod

## Project Structure

The project follows a fixed architecture separating:

- application routes
- reusable components
- page sections
- project components
- experience components
- certificate components
- animations
- 3D components
- data
- utilities
- hooks
- types

## Development

Install dependencies:

```bash
pnpm install
```
